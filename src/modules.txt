# Module Dependencies
core/
  - No dependencies on other modules
  - Other modules depend on core/

video/
  - Depends on: core/
  - Optional: graphics/

input/
  - Depends on: core/
  - Optional: system/ for force feedback

audio/
  - Depends on: core/

system/
  - Depends on: core/
  - Optional: various platform-specific

graphics/
  - Depends on: core/, video/

util/
  - Depends on: core/

test/
  - Can depend on any module

# Migration Steps
1. Create directory structure
2. Move existing files to new locations
3. Update imports in each file
4. Create module.zig files in each directory
5. Update build.zig for new structure
6. Update tests to reflect new organization
7. Document module relationships
